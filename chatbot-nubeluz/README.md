# Nubeluz | Chatbot para Moldes de Confección

Este proyecto contiene dos ejemplos funcionales en una sola página:

1. **Chatbot rectangular:** se muestra siempre como un contenedor visible para orientar sobre moldes, servicios y pedidos.
2. **Chatbot en burbuja:** aparece como un botón flotante y se abre al hacer clic.

## Cómo abrirlo

1. Abre la carpeta `chatbot-ejemplos`.
2. Haz doble clic en `index.html`.
3. Prueba escribir: `hola`, `moldes`, `servicios`, `pedidos` o `precio`.

## Personalización

- Cambia los textos de respuesta en `script.js`, dentro de `obtenerRespuesta`.
- Cambia colores, tamaños y ubicación en `styles.css`.
- Cambia el título y los mensajes iniciales en `index.html`.

## Subir el proyecto a GitHub

1. Crea un repositorio vacío en GitHub, por ejemplo `chatbot-html-css-js`.
2. En una terminal dentro de esta carpeta, ejecuta:

```powershell
git init
git add .
git commit -m "Crear ejemplos de chatbot"
git branch -M main
git remote add origin URL_DE_TU_REPOSITORIO
git push -u origin main
```

Reemplaza `URL_DE_TU_REPOSITORIO` por la dirección que GitHub te entrega.
